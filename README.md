# Big Brother: 1984 Tycoon

Атмосферный кликер-симулятор, вдохновленный антиутопией Джорджа Оруэлла «1984». Ваша задача — возглавить Министерство Любви и обеспечить тотальный контроль над населением.

## Как запустить
Игра полностью реализована на чистом HTML, CSS и JavaScript. 
1. Скачайте репозиторий проекта.
2. Откройте html файл в любом современном веб-браузере. Сервер не требуется.

## Core Loop (Основной цикл игры)
1. **Ручной сбор:** Кликайте на кнопку "ВЫЯВИТЬ ДИССИДЕНТА", чтобы получить стартовую валюту.
2. **Инвестиции:** Покупайте "Инструменты Контроля" (осведомители, камеры, прослушка), которые генерируют валюту автоматически.

## Экономика
*   **Валюта:** «Пойманные диссиденты».
*   **Источники дохода:** 
    *   Активный: Клик по кнопке (базовая мощность + бонусы).
    *   Пассивный: Инструменты контроля (определенное количество валюты в секунду).
*   **Прогрессия стоимости:** Стоимость каждого следующего инструмента контроля растет экспоненциально (множитель 1.15), что требует постоянного роста дохода для развития.

## Хранение данных
Весь прогресс игры сохраняется в `localStorage` вашего браузера.
*   Данные включают: текущее количество диссидентов, уровень каждого инструмента, купленные апгрейды клика и текущий этап игры.
*   Автосохранение происходит каждые 10 секунд.
*   Функция "Сбросить прогресс" полностью очищает данные из `localStorage`.

## Монетизация (Заглушки)
Игра содержит имитацию игровых покупок для придания антуража «корпоративного» контроля:
1. **Лавка МинИзобилия:** Интерфейс покупки премиум-бонусов (мгновенные бусты, удвоение дохода, автокликер).
2. **Телекракт-Реклама:** Имитация системы Rewarded Video. Игрок смотрит 3-секундный «пропагандистский ролик» (таймер) и получает бонус к валюте.
